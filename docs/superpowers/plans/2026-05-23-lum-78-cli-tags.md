# LUM-78 — CLI doc/task tags Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add tag management to `lumo doc create/update` and `lumo task create/update` via `--tag` / `--tag-id` (bulk set) on create + update, and `--add-tag` / `--add-tag-id` / `--remove-tag` / `--remove-tag-id` (incremental) on update.

**Architecture:** CLI resolves tag names to ids via a new `POST /api/tags/resolve` endpoint (wraps existing `tagRepository.findOrCreateMany`). Server schemas gain `tagIds` on create paths and `addTagIds` / `removeTagIds` on update paths, with a Zod `.refine` rejecting `tagIds` together with either incremental field. Repo gets four idempotent helpers (`add{Task,Document}Tags`, `remove{Task,Document}Tags`). Services branch on which field is present. Legacy `Document.tags: String[]` is left alone.

**Tech Stack:** Next.js 14 App Router · Prisma · Zod · Jest · TypeScript strict · Node 20 CLI (`cli/`).

**Spec:** [docs/superpowers/specs/2026-05-23-lum-78-cli-tags-design.md](../specs/2026-05-23-lum-78-cli-tags-design.md)

```ts
const tagsIncrementalShape = {
  addTagIds: z.array(z.string().cuid()).max(20).optional(),
  removeTagIds: z.array(z.string().cuid()).max(20).optional(),
} as const

const tagIdsShape = {
  tagIds: z.array(z.string().cuid()).max(20).optional(),
} as const

function refineTagsMutex<T extends { tagIds?: unknown; addTagIds?: unknown; removeTagIds?: unknown }>(
  schema: z.ZodType<T>
): z.ZodEffects<z.ZodType<T>> {
  return schema.refine(
    (v) => !(v.tagIds && (v.addTagIds || v.removeTagIds)),
    { message: 'tagIds and addTagIds/removeTagIds are mutually exclusive', path: ['tagIds'] }
  )
}
```

```ts
import { NextRequest, NextResponse } from 'next/server'
import { z } from 'zod'
import { requireWorkspace } from '@/lib/auth/workspace'   // anchor: same helper used by app/api/tags/route.ts
import { tagRepository } from '@/lib/repositories/tag.repository'

const bodySchema = z.object({
  names: z.array(z.string()).max(20),
})

export async function POST(req: NextRequest): Promise<Response> {
  const { workspaceId } = await requireWorkspace(req)

  const parsed = bodySchema.safeParse(await req.json())
  if (!parsed.success) {
    return NextResponse.json({ error: parsed.error.flatten() }, { status: 400 })
  }

  // Trim, drop empties, dedupe preserving order.
  const seen = new Set<string>()
  const cleaned: string[] = []
  for (const raw of parsed.data.names) {
    const t = raw.trim()
    if (t.length === 0) {
      return NextResponse.json(
        { error: 'tag names must not be empty after trim' },
        { status: 400 }
      )
    }
    const key = t.toLowerCase()
    if (seen.has(key)) continue
    seen.add(key)
    cleaned.push(t)
  }

  if (cleaned.length > 20) {
    return NextResponse.json({ error: 'too many names' }, { status: 400 })
  }

  const tags = await tagRepository.findOrCreateMany(workspaceId, cleaned)
  return NextResponse.json({ tags })
}
```

```ts
import { trimTrailingSlash } from './api'

export interface ResolveTagsDeps {
  apiUrl: string
  token: string
  fetchImpl?: typeof fetch
}

export interface TagRefs {
  names: string[]
  ids: string[]
}

interface ResolveResponse {
  tags: Array<{ id: string; name: string }>
}

export async function resolveTagRefs(
  refs: TagRefs,
  deps: ResolveTagsDeps
): Promise<string[]> {
  const fetchImpl = deps.fetchImpl ?? fetch

  // Trim + reject empty
  const trimmed: string[] = []
  for (const raw of refs.names) {
    const t = raw.trim()
    if (t.length === 0) {
      throw new Error('tag names must not be empty')
    }
    trimmed.push(t)
  }

  // Dedupe case-insensitively, preserve first-seen casing
  const seen = new Set<string>()
  const unique: string[] = []
  for (const t of trimmed) {
    const key = t.toLowerCase()
    if (seen.has(key)) continue
    seen.add(key)
    unique.push(t)
  }

  let nameIds: string[] = []
  if (unique.length > 0) {
    const url = `${trimTrailingSlash(deps.apiUrl)}/api/tags/resolve`
    const res = await fetchImpl(url, {
      method: 'POST',
      headers: {
        Authorization: `Bearer ${deps.token}`,
        'Content-Type': 'application/json',
      },
      body: JSON.stringify({ names: unique }),
    })
    if (!res.ok) {
      const body = await res.text()
      throw new Error(`tag resolve failed: ${res.status} ${res.statusText}: ${body}`)
    }
    const json = (await res.json()) as ResolveResponse
    nameIds = json.tags.map(t => t.id)
  }

  // Merge with explicit ids, dedupe
  const out = new Set<string>(nameIds)
  for (const id of refs.ids) out.add(id)
  return [...out]
}
```

- **Response shape verification (Task 7 Step 7-A, Task 9 Step 7):** the spec assumes the existing POST/PATCH handlers return `documentTags.tag` / `taskTags.tag` join data.
