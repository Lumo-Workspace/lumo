# Show Created Branches in Task Detail Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Persist branches created from tasks to the DB and display them in the task detail PR section.

**Architecture:** Add `TaskBranch` model to Prisma; save a record in `POST /api/tasks/:id/branch` after successful GitHub creation; include branches in GET task; render them in the PR section of both task detail views.

**Tech Stack:** Next.js 14 App Router, Prisma, TypeScript, Tailwind CSS, lucide-react.

## Task 1: Prisma schema + migration

### Step 1.1 — Add `TaskBranch` model to schema

Edit `/Users/chaoli/Desktop/lumo/lumo/prisma/schema.prisma`.

**a) Add `branches TaskBranch[]` to the `Task` model.**

Locate the `Task` model. It currently ends with:

```prisma
  pullRequests   PullRequest[]

  @@index([projectId])
  @@index([parentTaskId])
  @@map("tasks")
```

Change it to:

```prisma
  pullRequests   PullRequest[]
  branches       TaskBranch[]

  @@index([projectId])
  @@index([parentTaskId])
  @@map("tasks")
```

**b) Add the `TaskBranch` model** at the end of the file (after the last existing model):

```prisma
// ─── TaskBranch ──────────────────────────────────────────────────────────────

model TaskBranch {
  id         String   @id @default(cuid())
  taskId     String
  repo       String
  branchName String
  createdAt  DateTime @default(now())

  task Task @relation(fields: [taskId], references: [id], onDelete: Cascade)

  @@index([taskId])
  @@map("task_branches")
}
```
