# Task: LUM-844
**Title**: CLI: 瘦身 session attach / task context 输出,降低会话全程的上下文重读成本
**Status**: TODO
**Description**: ## 背景(token 用量分析,2026-09-25)

lumo 输出进入上下文后会被之后每个 step 重读(cache\_read),这部分成本在 `lumo cost` 里记在后续工具名下,不算 lumo。按「输出字符/3.5 × 剩余 step 数」估算,30 天本地 transcript 里:

-   `session attach`:125 次,平均 4.5K 字符,估算后续重读 ≈ 24.7M
-   `task context`:48 次,平均 6.7K 字符,估算后续重读 ≈ 22.2M 两者都在会话最开始(相对位置 ~0.1),剩余 step 最多,单位字符的代价最高。

## 目标

-   审计两者的输出:找出 attach 与 context 之间重复的段落(criteria 提醒、worktree 信息、Next 提示等)、低价值样板文字、可以折叠成一行 + 按需展开命令的大段(memory 全文、source cards、历史 session)
-   默认输出只保留开工必需的信息,细节改成渐进披露(给出 `lumo memory show <id>` / `--full` 之类的展开入口)
-   目标量级:单次输出减少 ≥50%,且不丢失开工必需信息

## 约束

-   不能删掉会影响正确性的信号(未处置 crossing、send-back、criteria 草拟提醒、Reference class 等);有疑问的保留
-   同步 SKILL.md / references、grammar.json、CLI 版本 bump(同一 PR)

## 关联

与 LUM-841 / 842 / 843 同属 lumo CLI token 优化。

## 验收思路

对固定 fixture 任务比较改动前后的输出字符数;transcript 复算 attach/context 单次平均字符数下降。

### Traps

- [project · agent-authored] **Session model uses many-to-one to a single task. User switches tasks within one session.** → All session work records under the final task only. Work on earlier tasks vanishes from records.
  Workaround: Split session on task switch, or add task array to session instead of single FK.
- [project · agent-authored] **Production secrets in .env.production or similar tracked by git** → Attackers read the credentials directly from history; they access prod database. You must rotate all exposed secrets and rebase to purge the file.
  Workaround: Add .env.production to .gitignore before commit. Use a separate secrets store (vault, CI secrets manager, AWS Secrets Manager) for prod values. Never commit a template with real values.
- [project · agent-authored] **Entry point eager-imports a module listed as devDependency or absent from package.json.** → MODULE_NOT_FOUND on every command. Package unusable at runtime, not caught at install.
  Workaround: Move all eager-imported modules to dependencies (not devDependencies). Test with fresh install before publish.
- [project · agent-authored] **Designing a task dependency feature.** → You build a manual declaration system that users must maintain → stale edges, high UX burden, low adoption.
